### Open Failed (sheet never opened after Check)

| MDS ID / Version | Why overall FAIL | What happened |
|---|---|---|
| 1490185359 / 1 | Recyclate FAIL and Biocidal FAIL | Search by ID returned **0 rows** |
| 1484116243 / 3 | Check 0E/1W; overall FAIL | Search by ID returned **0 rows** |

**Root cause (plain language):** After Check, the agent had to find each FAIL MDS again to reject it. It clicked Combined **None**, which clears every single status box (including **Browsed**). The log then said “Browsed checkbox already checked,” but the inbox was actually searching with **no status selected**, so IMDS reported **No results found**. The all-status retry clicked Combined **None** again and still found 0 rows.

Those two FAIL MDSs were therefore **not rejected** in this run. The Check results (FAIL) are still valid; only the reject click was missed.

This search bug was later fixed on `main` as [PR #22](https://github.com/rockyforever8-sys/Agentic-MDS/pull/22) (merged 27 August 2026, 08:11 UTC): after Combined None the agent always forces **Browsed** on, and the all-status retry uses Combined **All** instead of Combined None.
